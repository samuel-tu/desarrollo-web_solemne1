# Destino Cordillera - Plataforma de Turismo Local

Proyecto desarrollado para la evaluación práctica Solemne 01 de la asignatura **Desarrollo de Aplicaciones Web**. Consiste en un sitio web informativo y de promoción turística para la comuna ficticia **Destino Cordillera**, enfocado en destacar atractivos naturales, actividades al aire libre, servicios turísticos y canales de contacto.

## Descripción del Proyecto

El sitio web está estructurado en torno a cuatro secciones principales interconectadas mediante una navegación semántica y consistente:

1. **Inicio (`index.html`):** Portada principal con carrusel visual representativo, descripción general del destino cordillerano y tarjetas de acceso directo a los módulos clave.
2. **Panoramas (`panoramas.html`):** Catálogo de actividades recreativas, excursiones, rutas y atractivos turísticos organizados en tarjetas informativas.
3. **Alojamiento y Gastronomía (`alojamiento.html`):** Módulo informativo sobre alternativas de hospedaje y locales gastronómicos de la zona.
4. **Reserva y Contacto (`reserva.html`):** Formulario interactivo para cotizaciones y consultas de disponibilidad, junto con los canales de atención y un mapa con ubicación referencial.

---

## Tecnologías Utilizadas

* **HTML5:** Estructuración semántica del contenido (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, formularios accesibles).
* **CSS3:** Hoja de estilos externa personalizada (`css/style.css`), uso de variables CSS (`:root`), paleta cromática temática y diseño responsivo.
* **Bootstrap 5:** Framework frontend utilizado para componentes de interfaz, carrusel y sistema de grillas responsivas.
* **Git & GitHub:** Sistema de control de versiones distribuido y repositorio remoto para colaboración en equipo.
